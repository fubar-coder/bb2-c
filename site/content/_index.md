## What is bb2-c?

Blitz Basic 2 is a compiler for the BASIC dialect that many Amiga programmers
used for games and tools in the 1990s. bb2-c is a translation of it into C:
the compiler, the editor and the libraries that provide the commands.
The result runs on the Amiga (68000) and is built with a current cross
compiler instead of an assembler.

The goal of the translation is to behave like the original. Where it
differs on purpose, this site says so.
