The BB2 C port is a translation of Blitz Basic 2 into C: the compiler, the editor and
the libraries that provide the commands. The chapters below explain how to
build and use it, how it works inside, and where it differs from the
original. They are in reading order: the first chapters are for everyone who
wants to use the port, the last ones for people who write libraries or work
on the port itself.

## Where to start

* **You wrote Blitz Basic 2 programs and want to again.** Build the port,
  set up the emulator and write your first program
  ([Building the BB2 C port](/docs/introduction/building/),
  [Running it in an emulator](/docs/introduction/emulator/),
  [Your first program](/docs/introduction/first-program/)),
  then read [The editor](/docs/editor/),
  [How blitz2 works](/docs/how-blitz2-works/),
  [The language](/docs/language/) for looking up a
  statement or an operator,
  and [Differences from the original](/docs/compared-with-original/).
* **You want to work on the port.** After the Introduction, read
  [Project structure](/docs/project-structure/) and its
  [Tests](/docs/project-structure/tests/), then
  [How blitz2 works](/docs/how-blitz2-works/) and
  [Inside the compiler source](/docs/blitz2-internals/compiler-source/),
  and [Comparing with the original yourself](/docs/compared-with-original/comparing/).
* **You want to write a library.** After the Introduction and How blitz2
  works, follow the chapter
  [blitz2 internals](/docs/blitz2-internals/) up to
  [Writing your own userlib](/docs/blitz2-internals/own-userlib/)
  and [Library variants](/docs/blitz2-internals/variants/).
* **You use AmiBlitz3.** After the Introduction, read
  [AB3 mode](/docs/ab3-mode/) and
  [AB3 compared with blitz2](/docs/ab3-compared/).
