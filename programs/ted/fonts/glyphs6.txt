; glyphs6.txt - the glyphs $80-$FF of TED-C's 8 x 6 screen font and its
; redrawn glyph 26 (spec tooling/ted-font). The tool tedfont joins them
; with the glyphs 0-127 of TED 1.1 (archive/sources/ted-1.1/chars.b,
; unchanged) into the 256-glyph font ted_font6.b of the build directory,
; which TED-C embeds (programs/ted/src/core/res.c).
;
; Origin: no font has an 8 x 6 cell with TED's 2-px strokes, so these
; glyphs are drawn new in the style of TED's 6 px font, after the 8 px
; set (glyphs8.txt: unscii-8 by viznut, https://github.com/viznut/unscii,
; "Public Domain (or CC-0)", commit
; 257b4dfeb50651510fe8b9cf4f151a148a4490e4). They reuse TED's own
; letters: a lower-case letter with a mark is a one-row mark in row 0 on
; TED's unchanged letter (rows 1-4, descender row 5); a capital is a
; one-row mark on a 4-row capital. $F6 $FC $C4 $D6 $DC are TED's glyphs
; 27-31; $E4 is the redrawn glyph 26. Circumflex, tilde and ring are
; conventions, $BC $BD $BE $A7 $B6 approximations.
;
; Glyph 26 (TED's "a" with diaeresis, @1A): redrawn, the dots in row 0 on
; TED's unchanged "a" in rows 1-4 (the scheme of $E0-$E2); the original
; draws the dots, a gap and an arch, which reads as a cut-off "o" with
; diaeresis (docs/ted/deviations.md). Glyphs 27-31 stay as TED drew them.
;
; Format (tools/tedfont/README.md): comment lines start with ";", blank
; lines are ignored; "h=6", then per glyph a line "@XX" (the code in
; hexadecimal, a comment may follow) and 6 rows of 8 characters, "#" a
; set pixel and "." a blank one (the left character is bit 7). Every code
; $80-$FF is given exactly once; @1A may be given in addition.
;
; $80-$9F: one glyph, a hollow box with 1-px lines, for the C1 controls a
; text file can hold ($80 is never drawn: TED-C stores a byte $80 as "?").
; $A0 (no-break space): blank.
