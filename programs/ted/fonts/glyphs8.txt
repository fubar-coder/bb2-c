; glyphs8.txt - the glyphs $80-$FF of TED-C's 8 x 8 screen font (spec
; tooling/ted-font). The tool tedfont joins them with the glyphs 0-127 of
; TED 1.1 (archive/sources/ted-1.1/chars8.b, unchanged) into the
; 256-glyph font ted_font8.b of the build directory, which TED-C embeds
; (programs/ted/src/core/res.c).
;
; Origin: the glyphs $A1-$FF are unscii-8 by viznut
; (https://github.com/viznut/unscii), "Public Domain (or CC-0)" (the
; README of the repository), from fontfiles/unscii-8.hex of commit
; 257b4dfeb50651510fe8b9cf4f151a148a4490e4 (SHA-256 of the file
; 03094f7fbab7085cf6a6b624cee61e47e71ce5d0c2f308c2f4436afdc17f776c).
; Unchanged from unscii-8 (75; $C4 and $E4 are TED's glyphs 29 and 26 too):
;   $A1 $A2 $A3 $A4 $A5 $A6 $A7 $A8 $A9 $AA $AB $AC $AD $AE $AF $B0 $B1 $B2
;   $B3 $B4 $B5 $B6 $B7 $B8 $B9 $BA $BB $BC $BD $BE $BF $C0 $C1 $C2 $C3 $C4
;   $C5 $C6 $C7 $CA $CC $CD $CE $CF $D0 $D1 $D4 $D5 $D7 $D8 $DB $DD $DE $DF
;   $E0 $E1 $E2 $E3 $E4 $E5 $E6 $EA $EE $F0 $F1 $F2 $F3 $F4 $F5 $F7 $F8 $FB
;   $FD $FE $FF
; Adapted to TED's letters (20; the comment of each block says how):
;   $C8 $C9 $CB $D2 $D3 $D6 $D9 $DA $DC $E7 $E8 $E9 $EB $EC $ED $EF $F6 $F9
;   $FA $FC
; Drawn new: $80-$9F and $A0.
;
; Format (tools/tedfont/README.md): comment lines start with ";", blank
; lines are ignored; "h=8", then per glyph a line "@XX" (the code in
; hexadecimal, a comment may follow) and 8 rows of 8 characters, "#" a
; set pixel and "." a blank one (the left character is bit 7). Every code
; $80-$FF is given exactly once.
;
; $80-$9F: one glyph, a hollow box with 1-px lines, for the C1 controls a
; text file can hold ($80 is never drawn: TED-C stores a byte $80 as "?").
; $A0 (no-break space): blank.
