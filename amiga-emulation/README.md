# Emulation data (not in the repository)

The local Kickstart ROMs and hardfiles for the emulator tests live here;
they are not checked in. What belongs here: `../AMIGA-EMULATION-SETUP.md`.
When a machine is added (e.g. the a500-204 with Kickstart 2.04 and
Workbench 2.1), run the setup again: existing files stay untouched, the
new ones are added.
