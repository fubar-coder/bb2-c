# What a change of a file selects (covsel, README "Coverage"): per line a
# path pattern (relative to the repository; '*' within a directory, '**'
# across directories, "**/" also none) and selectors.  The first matching
# rule counts; a file no rule matches selects all tests.  Selectors: all,
# none, coverage (the tests of the changed functions, by the map), header
# (the tests of the objects that include the file), label:LABEL,
# name:PATTERN (ctest names; host tests are host/NAME).  Never fewer tests
# than a change can affect: when in doubt, all.
