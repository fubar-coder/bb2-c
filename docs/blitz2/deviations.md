# Deviations of the C compiler from Blitz Basic 2 2.10

Reference: the compiler of the CD (2.10), built from `blitz2.s`
(`archive/`, [../v2.10/README.md](../v2.10/README.md)). All known places
where `programs/blitz2` (and the code in `shared/` it uses) behaves
differently. Basis: all `DIFF` markers in `programs/blitz2/src`, the
fixed original bugs (`Fixed (#N)` in the comments) and the project
conventions. `BUG(orig)` (original bugs not fixed yet) is marked in the
code and listed here only where an entry describes it.

Rule (CLAUDE.md "Original bugs are fixed deliberately"): original bugs
are fixed deliberately, one issue per bug; every fix is listed here as an
intended deviation (kind **F**) with its issue and its test, in the
commit of the fix. Other deviations only where they are technically
unavoidable, with a reason, marked `DIFF:` in the code.
Categories as in [`../libs/deviations.md`](../libs/deviations.md)
(**B** decided by the user, **T** technically unavoidable, **K** silent
correction - not permitted, **F** fixed original bug). The fixes of the
libraries are listed there, those of TED in
[`../ted/deviations.md`](../ted/deviations.md).

Produces byte-identical programs (test corpus and CD reference run), hence only
internal deviations; except the fixed original bugs (kind **F**), which
change the generated code of the programs they concern. Conventions: `-fbaserel` (globals a4-relative,
`GLUE_LOAD_A4` in all entry points from outside, [README](bb2-readme.md)), assembler only in
`programs/blitz2/src/glue*.c`, registers with persistent state as globals
(`srcptr`; `numval`/`numfloat` local to libcall.c).
